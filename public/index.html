F-08 · PDF & Word

Word ⇄ PDF Conversion

Format conversion needs Word (or LibreOffice) actually installed — a browser tab can't render an .docx into a real PDF layout, so this can't be done as a pure web tool.

Keep using your existing script for this one Word_2_PDF_Conversion.bat and the Word/PDF/Image converter already do this correctly because they drive real Microsoft Word on your machine. That's the right tool for the job — this website can't replace it without Word installed in the browser, which isn't possible.

If you'd rather not use Word

Install LibreOffice (free) and run this from a command prompt in the folder of files — it converts every .docx to .pdf without opening Word:

soffice --headless --convert-to pdf *.docx

What the Enterprise Layer adds

  • Audit log — every add/edit/delete is captured (actor, action, entity, before → after diff), persisted in the JSON DB under meta.audit
  • Rolling backups — up to 30 full-DB snapshots kept in-browser (IndexedDB), one-click restore
  • RBAC — Viewer / Editor / Admin; destructive actions require admin
  • AES-GCM encryption at rest (optional, per-file passphrase)
  • Session lock — idle auto-lock + manual lock
  • Global search palette — instant lookup across cases, visas, clients, commands
  • Validation layer — passport format, expiry sanity, duplicate detection
  • Health check — orphan links, duplicates, schema version
  • Dark mode, WCAG-AA focus rings, offline banner, print/PDF report styles
  • Schema migrations — safely upgrades older DB files on open
